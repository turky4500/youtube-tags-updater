# YouTube Tags Updater v2

أداة لتحسين وسوم فيديوهات يوتيوب بالملاءمة لا بالحشو.

## ما الذي تغيّر عن النسخة القديمة؟
- لا يُضاف أي وسم غير مرتبط بموضوع الفيديو (إلغاء الترندات العشوائية).
- مصدر الكلمات = اقتراحات بحث يوتيوب الحقيقية بدلاً من ترند جوجل.
- تعديل الفيديوهات التي تحتاج فقط (جديدة أو قليلة الوسوم) + فترة 30 يوم.
- سجل تغييرات change_log.json لقياس الأثر.
- دعم DRY_RUN للتجربة الآمنة، وتعطيل الهاشتاقات افتراضياً.

## المتغيرات البيئية
- CLIENT_SECRET_JSON_B64 و TOKEN_PICKLE_B64: كما هما بدون تغيير.
- DRY_RUN = "1": تجربة بدون تعديل حقيقي.
- ADD_HASHTAGS = "1": تفعيل إضافة الهاشتاقات للوصف.

## ملاحظة
الوسوم وحدها لا ترفع المشاهدات؛ النمو يأتي من CTR (العنوان + الصورة المصغرة)
والاحتفاظ بالمشاهدة (جودة المحتوى).
