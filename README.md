# YouTube Comprehensive Optimizer v3

أداة لتحسين بيانات فيديوهات يوتيوب آلياً بالملاءمة، دون إضافة كلمات ترند عشوائية.

## ماذا تحسّن الأداة؟

كل يوم تختار الأداة 3 فيديوهات وتحدّث:

- **العلامات (Tags):** حتى 12 علامة مأخوذة من عنوان الفيديو واقتراحات بحث يوتيوب المرتبطة به.
- **الوصف:** إعادة تنظيم الوصف، مع الحفاظ على المعلومات الأصلية المفيدة وإزالة إضافات السكربت القديمة.
- **الهاشتاقات:** إضافة حتى 5 هاشتاقات مرتبطة بالعنوان والمحتوى؛ إذا لم تتوفر 5 عبارات مرتبطة تستخدم الأداة عدداً أقل بدلاً من الحشو.

تمر الأداة على جميع فيديوهات القناة، حتى التي لديها علامات كثيرة. تعطى الأولوية للفيديوهات التي لم تعالجها النسخة الحالية، وبعد اكتمال الدورة لا يعاد تحسين الفيديو قبل مرور 30 يوماً.

## الجدول

يعمل GitHub Actions يومياً الساعة:

- `02:00 UTC`
- `05:00 صباحاً بتوقيت الرياض`

ومع 99 فيديو تقريباً، تستغرق الدورة الأولى حوالي 33 يوماً.

## التشغيل التجريبي

يمكن تشغيل الـWorkflow يدوياً من تبويب Actions وتفعيل خيار `dry_run` لمعاينة العلامات والهاشتاقات دون تغيير فيديوهات القناة.

## الأسرار المطلوبة

- `CLIENT_SECRET_JSON_B64`
- `TOKEN_PICKLE_B64`

## السجلات

- `update_log.json`: تاريخ آخر تحديث لكل فيديو.
- `change_log.json`: آخر تغييرات العلامات والهاشتاقات وحالة تغيير الوصف، مع الاحتفاظ بآخر 5 تغييرات لكل فيديو.

> العلامات والهاشتاقات أدوات مساعدة فقط. العنوان والصورة المصغرة وجودة المحتوى والاحتفاظ بالمشاهد عوامل أهم في نمو المشاهدات.
